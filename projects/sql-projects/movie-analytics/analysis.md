# Movie Analytics – SQL Case Study

This project analyzes a movie dataset stored in Google BigQuery.  
The goal is to explore genre trends, revenue patterns, and rating distributions using analytical SQL.

## Technologies
- Google BigQuery (SQL)
- Window Functions
- Aggregations & Grouping
- Data Profiling
- Time‑based Analysis

## Summary of Work
### Schema Engineering
Defined a clean schema for movie metadata including genre, rating, release year, and revenue.

### Exploratory Analysis
Performed structural validation:
- Null checks  
- Genre distribution  
- Rating distribution  
- Yearly movie counts  

### Genre Trends
Analyzed:
- Most common genres  
- Genre popularity over time  
- Average ratings by genre  

### Revenue Insights
Generated insights on:
- Highest‑grossing movies  
- Revenue by genre  
- Revenue by release year
